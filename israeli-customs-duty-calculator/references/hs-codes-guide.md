# Israeli HS Code Classification Guide

Israel's Customs and Purchase Tax Tariff is built on the international Harmonized System. The first 6 digits of an item are the international HS code; the digits after them are Israeli subdivisions that set the duty, the purchase tax and the import conditions.

## How Shaar Olami shows an item

Shaar Olami displays each tariff item as a 10-digit code followed by a check digit after a slash. Examples read on the site on 18 October 2026:

| Code as displayed | Item |
|---|---|
| `2208300000/4` | Whiskies |
| `2402200000/4` | Cigarettes containing tobacco |
| `8708999000/3` | A line of motor-vehicle parts |

Work with the full code exactly as displayed. Do not truncate it to 8 digits and do not pad a foreign code to fit.

## How to look up a code

1. Open Shaar Olami at `https://shaarolami-query.customs.mof.gov.il/CustomspilotWeb/en/CustomsBook/Import/Doubt` and continue to the tariff book.
2. Search by customs item number or by word or phrase.
3. Drill down to the leaf item.
4. Read the item page:
   - the customs-tax table, one row per agreement, with the rate and the statistical unit
   - the purchase-tax table (tax rate, measurement unit, validity dates)
   - the legal requirements: Free Import Order and personal import order annexes, the certifying authority, and whether each one applies to personal imports
   - classification guidelines for the heading

## Chapters

The chapter is the first 2 digits. The two chapters this skill uses as examples, as titled in Shaar Olami: chapter 85, "Electrical machinery and equipment and parts thereof"; chapter 22, "Beverages, spirits and vinegar". Browse the section and chapter list in the tariff book rather than relying on a memorised table.

## Advance classification decision

If the classification is unclear, request an advance classification decision from Israeli Customs. **Whether it carries a fee, and how far it binds the authority, are not verified in this file: ask the customs house when you file.** Submit:
- A detailed description of the goods
- A catalog or technical data sheet
- Photos or samples if relevant
- Intended use

A decision of this kind is generally relied on for the specific product described, and an inaccurate description undermines it. The precise legal effect is not verified here.

## Differences from US HTS and EU CN

Israel, the US, and the EU all share the first 6 digits of the HS code (the international standard). Beyond that each has its own subdivisions, so a US HTS code or an EU CN code cannot be mechanically translated to an Israeli tariff item. Always re-classify via Shaar Olami.
